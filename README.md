## How to use this skill in Microsoft Scout

1. Open Microsoft Scout.
2. Go to Skills or custom skills.
3. Create a new custom skill.
4. Copy the contents of `skill.md`.
5. Paste it into the skill instructions field.
6. Save the skill.
7. Invoke it in Scout when you want to use it.

## Example prompt

Use this skill to help me draft an email to individuals and their managers to identify S360 action items with missing ETA
